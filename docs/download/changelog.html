更新后，小组件还没变化怎么办？

先打开一次森森课表，确认课表正常，再进入「设置 → 刷新小组件」。仍未恢复时，可移除后重新添加，并检查系统是否限制了应用后台运行。

开了提醒，为什么还需要系统权限？

应用内的开关负责安排提醒，系统通知权限决定通知能否显示，「闹钟和提醒」权限则用于准时调度。请按应用提示完成授权；在提醒时间之后才开启，不会补发已经错过的提醒。
